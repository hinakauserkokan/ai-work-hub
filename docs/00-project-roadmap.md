# AI Work Hub roadmap

## Product goal

AI Work Hub helps small teams organise work and preserve decisions. AI will assist with meeting notes only after the basic work-management experience is reliable.

## Delivery order

1. **App shell and navigation** — shared sidebar, top bar, routes, and a dashboard prototype. Complete.
2. **Projects and task-board frontend** — project list, Kanban columns, task cards, filters, and temporary interactive state. Complete.
3. **Persistence** — domain models, Entity Framework Core, PostgreSQL, migrations, and CRUD services. Complete.
4. **Accounts and teams** — authentication, memberships, roles, and authorization.
5. **Collaboration** — comments, activity history, and real-time updates.
6. **Insights** — work-load and project-health calculations.
7. **AI meeting assistant** — secure server-side AI calls, structured suggestions, user review, and audit records.
8. **Release readiness** — validation, tests, error handling, accessibility, and deployment.

## Version 1 scope

Projects, tasks, statuses, assignees, priorities, due dates, comments, activity history, meetings, and approved AI task suggestions.

## Intentionally deferred

File storage, external calendar sync, email notifications, and autonomous AI actions. These are valuable but would make the first release harder to learn and validate.
